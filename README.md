# Info
MSource is a fork of Source 2013 CE, and we intend on adding graphical improvements and better PointEnts for mappers.

It is built for a Half-Life 2 mod currently in development by MIXX Brigade staff.

# Requirements 
To be able to use Source 2013 CE you will need to download **Visual Studio 2022** and install:
* MSVC v143 - VS 2022 C++ x64/x86 build tools
* C++ MFC Library for latest v143 build tools (x86 and x64)
* Windows 11 SDK (10.0.22000.0)
